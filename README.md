# 🎨 Color Guessing Game  
An interactive and fun RGB color-matching game built with **HTML**, **CSS**, and **JavaScript**.

## 🌟 About the Game  
**Color Guessing Game** challenges users to match a randomly generated **RGB color code** with the correct color box. It’s a simple yet engaging game that sharpens visual perception and improves understanding of how RGB values translate into colors.

## 🚀 Features  
- 🎯 **Two Difficulty Modes**:  
  - **Easy** – 6 color options  
  - **Hard** – 9 color options  
- 🎨 **Dynamic Color Generation**: New RGB values and corresponding colors in each round.
- ✅ **Instant Feedback**:  
  - *Correct Guess* – Displays “Correct Answer” and resets the board.  
  - *Wrong Guess* – Shows “Wrong Answer” and allows further attempts.  
- 🔁 **Game Reset Functionality**: Board resets automatically after a correct guess or manually.
- 🧠 **Enhances RGB Color Recognition Skills**

## 🎮 How to Play  
1. A target **RGB value** is displayed at the top.
2. Click on the box that you think matches that color.
3. If correct – a success message is shown, and the board resets.  
   If wrong – continue until you select the right one.
